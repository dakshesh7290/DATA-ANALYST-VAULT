# Data Analyst Vault

> A complete, public knowledge base for learning, practicing, and preparing for a career as a Data Analyst.

## What This Vault Is

This vault is an end-to-end knowledge system covering everything involved in becoming and working as a Data Analyst — from foundational tools and technical skills, through statistical reasoning, to job preparation and career context. It is built to function as a learning resource, a revision library, an interview preparation guide, and a long-term reference that can be revisited at any stage of a Data Analyst's career.

## Who This Vault Is For

- Beginners exploring whether a Data Analyst career is a good fit
- Students building foundational skills
- Career switchers moving into analytics
- Junior Data Analysts strengthening their technical base
- Working analysts using it as a reference or revision tool
- Anyone preparing for Data Analyst interviews

No prior data experience is assumed. Concepts are explained from first principles, then extended to the depth needed for real analyst work and interviews.

## What This Vault Contains

- **Skills Hub** — Excel, SQL, Power BI, Python, Statistics, and AI, each broken into focused sub-topics
- **Workflow** — the end-to-end process a Data Analyst follows on a real project
- **Data Job Profiles Comparison** — how the Data Analyst role differs from Data Engineer and Data Scientist roles
- **Beyond Core** — supporting knowledge (APIs, Git & GitHub, Cloud, Data Warehousing, ETL, CRM) that deepens technical range
- **Job Prep** — resume guidance, portfolio building, interview questions, and project ideas

## How This Vault Is Organized

The vault does not rely on folder browsing. Instead, it is organized around **Maps of Content (MOCs)** — index notes that link out to everything relevant in a given area. Start from this Home note or the [[Data Analyst]] note, and follow the links outward rather than searching through folders.

```
Home → Data Analyst (master map) → Skills Hub / Workflow / Job Profiles / Beyond Core / Job Prep
```

Each Skills Hub topic (e.g. SQL) has its own MOC note that links to every sub-topic underneath it.
