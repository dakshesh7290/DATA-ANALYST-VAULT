# Data Analyst Vault

A complete, public knowledge base covering everything involved in becoming and working as a Data Analyst — from foundational tools and technical skills, through statistical reasoning, to job preparation and career context.

This started as a personal learning project and grew into a full end-to-end resource: **Excel, SQL, Power BI, Python, Statistics, and AI**, plus supporting topics (APIs, Git, Cloud, Data Warehousing, ETL, CRM) and job-prep material (resume tips, portfolio guidance, 100 interview questions, 20 project ideas).

Built and maintained in [Obsidian](https://obsidian.md), using a Maps of Content (MOC) structure for navigation.

## How to Navigate

This vault is built around **Maps of Content (MOCs)** rather than folder browsing:

```
Home → Data Analyst (master MOC) → Skills Hub / Workflow / Beyond Core / Job Prep → individual notes
```

- **Viewing on GitHub:** browse folders directly, or start at [`1. HOME/DATA ANALYST VAULT.md`](<1.%20HOME/DATA%20ANALYST%20VAULT.md>)
- **Viewing in Obsidian (recommended):** clone or download this repo and open the folder as a vault — internal `[[links]]`, backlinks, and the graph view all work as intended, which GitHub's plain file viewer can't fully render

## Using This Vault

- **Learning** — follow the [`LEARNING ROADMAP`](<2.%20MAP%20OF%20CONTENT/LEARNING%20ROADMAP.md>) for a suggested path from foundations to job-ready
- **Revision** — every technical note ends with a Revision Summary for quick review
- **Interview prep** — see `5. JOB PREP/TOP 100 QUESTIONS.md`, plus the Interview Perspective section in most technical notes

## Cloning This Vault

git clone https://github.com/dakshesh7290/DATA-ANALYST-VAULT
