# Structured Query Language (SQL)

> The language used to query, filter, and summarize data directly from databases — arguably the single most important Data Analyst skill.

## What It Is

A standardized language for retrieving and manipulating data stored in relational databases, built around statements like `SELECT`, `WHERE`, and `JOIN`.

## What It Does

Lets you request exactly the data you need — filtered, sorted, joined across tables, and summarized — directly from the source, without exporting entire tables.

## When It's Used

- Pulling data directly from a company's database for analysis
- Combining data from multiple related tables (e.g. orders and customers)
- Summarizing large datasets (totals, averages, counts) far larger than Excel can comfortably handle
- Powering the queries behind BI tool dashboards and reports
