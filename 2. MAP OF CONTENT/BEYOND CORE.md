# Beyond Core

> Supporting knowledge that extends beyond the core Data Analyst toolset — not always required for entry-level roles, but valuable for technical depth, collaboration, and career progression.

## Overview

The topics in this section — APIs, Git & GitHub, Cloud Migration, Cloud Architecture, Customer Relationship Management (CRM), Data Warehouse, and Extract, Transform, Load (ETL) — aren't part of the core day-to-day toolkit for most entry-level Data Analyst roles. However, understanding them meaningfully improves an analyst's ability to collaborate with Data Engineers, work with modern data infrastructure, and grow into more senior or specialized positions.

## Why This Section Exists

As organizations mature their data infrastructure, analysts increasingly need to understand — even if they don't directly build — the systems their data flows through. An analyst who understands basic cloud architecture or how ETL pipelines work can communicate more effectively with engineering teams, diagnose data issues more independently, and make better-informed recommendations.

## What This Section Is Not

This section deliberately does not turn into a Data Engineering curriculum. Each note is scoped specifically to what a Data Analyst needs to understand — not the depth required to build or maintain these systems.

## Topics

- **APIs** — how analysts extract data from external systems programmatically
- **Git & GitHub** — version control for scripts, queries, and documentation
- **Cloud Migration** — why and how organizations move data infrastructure to the cloud
- **Cloud Architecture** — the components of a typical cloud data environment
- **Customer Relationship Management (CRM)** — a common business data source
- **Data Warehouse** — how organizations structure data for analytical use
- **Extract, Transform, Load (ETL)** — how data moves from source systems into analysis-ready form
