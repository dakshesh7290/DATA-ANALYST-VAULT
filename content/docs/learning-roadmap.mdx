> A phased path through this vault, from foundational skills to job readiness and beyond.

## Overview

This roadmap suggests an order to work through the vault's content. It's a guide, not a strict requirement — skip ahead or double back as your own background and goals require.

## Phase 1 — Foundations

- Excel — basics and core formulas
- Basic SQL — SELECT, WHERE, JOIN fundamentals
- Basic statistics — descriptive statistics, core concepts
- Data concepts — what a Data Analyst actually does (see [DATA ANALYST](/docs/map-of-content/data-analyst))

**Goal:** Comfortable pulling and summarizing data using the two most universally required tools.

## Phase 2 — Core Analyst Skills

- Advanced SQL — joins, subqueries, window functions
- Power BI — data modeling, DAX, dashboards
- Data cleaning — across Excel and SQL
- EDA — structured exploratory analysis
- Business KPIs — connecting metrics to business questions

**Goal:** Able to take a raw dataset through cleaning, analysis, and a polished, stakeholder-ready dashboard.

## Phase 3 — Programming

- Python — language fundamentals
- NumPy — array operations
- Pandas — the core data manipulation library
- Matplotlib — visualization
- Automation — scripting recurring tasks

**Goal:** Able to perform deeper, more flexible analysis than Excel/SQL alone allow, and automate repetitive work.

## Phase 4 — Analytical Depth

- Statistics — probability, distributions
- Hypothesis testing
- Regression
- A/B testing

**Goal:** Able to distinguish real patterns from noise, and speak credibly about *why* a finding is (or isn't) statistically sound.

## Phase 5 — Job Readiness

- Projects — building a portfolio (see [TOP 20 PROJECTS](/docs/job-prep/top-20-projects))
- Resume — see [RESUME TIPS](/docs/job-prep/resume-tips)
- Portfolio — see [PORTFOLIO BUILDING GUIDE](/docs/job-prep/portfolio-building-guide)
- Interview preparation — see [TOP 100 QUESTIONS](/docs/job-prep/top-100-questions)

**Goal:** A complete, demonstrable body of work and the materials to apply and interview effectively.

## Phase 6 — Beyond Core

- APIs — pulling data from external systems
- Git & GitHub — version control and portfolio hosting
- Data warehouses — how analytical data is structured
- ETL — how data moves from source to analysis-ready form
- Cloud — migration and architecture basics
- CRM — a common business data source

**Goal:** Broader technical fluency that supports collaboration with engineering teams and deeper infrastructure understanding.

## Phase 7 — AI-Augmented Analyst

- AI tools — practical day-to-day usage
- Prompt engineering — getting better output from AI tools
- AI-assisted automation — combining AI with scripted workflows
- AI-assisted workflows generally

**Goal:** Using AI as a genuine productivity multiplier, with the judgment to verify its output rather than trust it blindly.

## Prerequisites and Order

- Phase 1 is a prerequisite for everything else — don't skip straight to Python or statistics without SQL/Excel fluency first.
- Phases 2 and 3 can be done in either order or in parallel, depending on whether SQL/BI or programming feels like the stronger starting interest.
- Phase 4 benefits from Phase 2/3 being at least partially in place, since statistical concepts are easier to apply once there's real data-handling fluency.
- Phase 5 should begin once Phases 1–3 are solid — a portfolio project draws on exactly those skills.
- Phases 6 and 7 can be picked up at any point after Phase 2, as they support rather than gate the rest of the path.
