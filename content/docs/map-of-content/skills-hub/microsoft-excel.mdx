> Spreadsheet software used for calculations, quick analysis, and reporting — one of the two most universally expected Data Analyst tools.

## What It Is

A spreadsheet application organized into cells, rows, and columns, with built-in formulas, charting, and data tools.

## What It Does

Lets you enter, calculate, summarize, and visualize data directly in a grid, using formulas that recalculate automatically when the underlying data changes.

## When It's Used

- Quick, one-off analysis on small-to-medium datasets
- Building reports and dashboards for stakeholders who expect a spreadsheet
- Sanity-checking output pulled from SQL or Python
- Lightweight, ad hoc calculations that don't justify a full BI tool
