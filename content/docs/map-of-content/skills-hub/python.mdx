> A programming language used for deeper, more flexible data analysis, automation, and working with files and APIs — beyond what Excel or SQL alone can do.

## What It Is

A general-purpose, readable programming language, used in analytics primarily through its data-focused libraries: NumPy (numerical arrays), Pandas (tabular data), and Matplotlib (charts).

## What It Does

Lets you write repeatable, scriptable steps for cleaning, transforming, analyzing, and visualizing data — and automate tasks that would otherwise require manual repetition.

## When It's Used

- Analysis too complex or multi-step for Excel/SQL alone
- Automating recurring tasks (cleaning a new file every week, combining several data sources)
- Pulling data from APIs or files not accessible via a database
- Deeper exploratory analysis with more flexible visualization than spreadsheet tools
