> The analytical reasoning that lets an analyst distinguish real patterns from random noise, and draw sound conclusions from data.

## What It Is

The mathematical framework for summarizing data, reasoning about uncertainty, and testing whether an observed pattern is likely to be real or coincidental.

## What It Does

Provides tools to describe a dataset (mean, median, spread), model relationships between variables (regression), test whether an effect is real (hypothesis testing), and design experiments that support causal conclusions (A/B testing).

## When It's Used

- Summarizing a dataset's central tendency and spread before deeper analysis
- Testing whether a difference between two groups is statistically meaningful
- Evaluating whether a product or marketing change genuinely caused an improvement
- Avoiding the common trap of mistaking correlation for causation
