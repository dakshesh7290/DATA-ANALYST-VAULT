> A guide to navigating, studying, and getting the most out of this Data Analyst knowledge vault.

## What Is This Vault?

This vault is a structured, end-to-end knowledge base covering the skills, workflow, and career context needed to become and work as a Data Analyst. It is designed to be read non-linearly — as a reference you return to — rather than as a single document read start to finish.

## Who Should Use It?

- **Beginners** with no prior data background exploring the field
- **Aspiring Data Analysts** actively building skills
- **Students** supplementing formal coursework
- **Career switchers** moving into analytics from another field
- **Junior Data Analysts** reinforcing fundamentals on the job
- **Working analysts** using it as a quick reference
- **Interview candidates** preparing for Data Analyst interviews

## How to Navigate

This vault uses **Maps of Content (MOCs)** instead of relying on folder structure. A MOC is an index note whose only job is to link out to related notes. Navigation generally works like this:

```
Home → Data Analyst (master MOC) → Skills Hub / Workflow / Beyond Core / Job Prep → individual notes
```

You rarely need to browse folders directly — click through links instead, the same way you would browse a well-organized website.

## How to Access Different Topics

- **Home** — entry point and overview
- **Map of Content** — the central index for the whole vault
- **Skills Hub** — links to Excel, SQL, Power BI, Python, Statistics, and AI, each with its own sub-MOC
- **Beyond Core** — supporting topics beyond the core toolset
- **Job Prep** — resume, portfolio, and interview material
- **Internal links** — every note links to related notes at the bottom under "Related"
- **Backlinks** — use Obsidian's backlink panel to see which notes reference the one you're reading
- **Search** — use Obsidian's search for a specific term across the whole vault

## What Information Is Provided?

Most technical notes follow a consistent structure: an overview, why the topic matters for a Data Analyst, core concepts, examples, common mistakes, best practices, and an interview-focused section. Career and workflow notes are structured around real analyst practice rather than abstract theory.

## How to Study Using the Vault

1. Start with the role-context notes ([DATA ANALYST](/docs/map-of-content/data-analyst), [DATA JOB PROFILES COMPARISON](/docs/map-of-content/data-job-profiles-comparison)) to understand what the job actually involves.
2. Work through one skill area at a time rather than jumping between tools.
3. Read a topic's full note once, then rely on its Revision Summary for repeated review.
4. Apply what you learn immediately — most notes include practical examples you can try yourself.
5. Revisit [WORKFLOW](/docs/map-of-content/workflow) periodically to see how individual skills connect into a full analyst process.

## How to Revise

Each technical note ends with a **Revision Summary** — a short, condensed version of the note. Use these for spaced repetition: skim the summaries regularly, and only return to the full note when a summary point feels unclear.

## How to Prepare for Interviews

- Use each note's **Interview Perspective** section to identify what interviewers commonly test.
- Work through [TOP 100 QUESTIONS](/docs/job-prep/top-100-questions) by category, not all at once.
- Review [TOP 20 PROJECTS](/docs/job-prep/top-20-projects) to practice explaining a project end-to-end, since interviews frequently probe past project work in depth.
- Pay attention to **Common Traps** sections — these flag the mistakes that most often distinguish weak answers from strong ones.

## How to Use the Vault Publicly

This vault is written to be usable by anyone, not just its author. Notes avoid first-person narrative, define technical terms on first use, and avoid assuming prior context. If you are sharing or publishing from this vault, this structure is intended to hold up without additional explanation.

## Recommended Learning Path

**Beginner** — role context, Excel basics, SQL basics, foundational statistics
**Intermediate** — advanced SQL, Power BI, Python fundamentals, data cleaning, EDA
**Job Ready** — full [WORKFLOW](/docs/map-of-content/workflow) fluency, a small portfolio of projects, resume and interview prep
**Advanced** — deeper statistics (regression, A/B testing), automation, Beyond Core topics, AI-assisted workflows
